# Ritual

Three small daily practices in one page: **Incantation**, **Gym**, **Breathing**. Built to be
added to an iPhone home screen, where it opens full screen with no browser chrome and works
offline once loaded. More tabs may get added later — the structure below is built for that.

Live at **https://nati-nath.github.io/incantations/** — the GitHub repo is still named
`incantations` (renaming it would change this URL and break the home screen shortcut until
re-added), even though the app and the local folder are now called Ritual.

## Incantation tab

Shows one incantation a day. Not at random, and not from the date — it's a **rotation**: the
app walks `incantations/incantations.json` in file order, one line per day, wrapping back to
the top at the end. So every line is seen exactly once per cycle, currently 103 days.

The position is stored on the device rather than derived from the date, so editing the
collection never changes the line already showing for today.

**♡ Love it** marks a line. **✕ Not for me** drops it out of the rotation immediately. Both are
stored on the device only, never in this repo. The counter at the bottom opens a panel with a
Copy button that exports the rejected ids, so they can be deleted from the JSON for good — the
only way votes make it off the phone, deliberately, so nothing about what you rejected is ever
published.

103 lines, each tagged with a `category` recording how well-sourced it is:

| category | count | what it is |
|---|---|---|
| `incantation` | 6 | Robbins' own incantations, from his event manuals |
| `primary-question` | 1 | His stated Primary Question |
| `winners-creed` | 10 | The Winner's Creed from a Life Mastery manual, adapted from Napoleon Hill |
| `quote` | 31 | Robbins speaking or writing, usable in the first person |
| `event-manual` | 33 | Quotes by **other** people, collected in his manuals |
| `circulating-online` | 22 | Widely shared in Robbins-adjacent lists but **not traceable to him** |

The last group is shown in gold in the app labelled "Widely shared, but not traceable to
Robbins", rather than being passed off as his. Sourced chiefly from
unleashyourinnerstrength.com, which reproduces material from Unleash the Power Within, Date
With Destiny, Wealth Mastery, Life Mastery and Leadership Academy manuals.

## Gym tab

15 movements, a minute each, back to back, driven by `gym/movements.json`. Each movement has a
simple line illustration in `gym/photos/`, generated by `gym/make-illustrations.py` — an
original drawing, not a photo of anyone, standing in until real photos of the actual positions
replace them.

## Breathing tab

A repeating inhale / hold / exhale / hold cycle, driven by `breathing/presets.json`. Any phase
set to 0 seconds is skipped — that's how 4-7-8 (no second hold) and coherent breathing (no
holds at all) reuse the same four-number shape. Presets are just quick-fill buttons; the
steppers are the actual source of truth, and your last-used seconds are remembered on the
device.

## Files

```
index.html                the whole app: markup, styles and logic for all three tabs
manifest.webmanifest      app name and colours for the home screen
icon-180.png, icon-512.png  home screen icons
make-icon.py               regenerates the icons

incantations/
  incantations.json        the collection. File order is rotation order. `id` is permanent

gym/
  movements.json           the 15 movements, in run order
  photos/                  one illustration per movement, referenced by movements.json
  make-illustrations.py    regenerates them — original line figures, not photos of anyone

breathing/
  presets.json              named breathing techniques (box, 4-7-8, coherent, pursed-lip)
```

Each tab owns one folder for its data, named to match. `index.html` is the shared shell —
tabs, styling, and the timer/rotation logic for all three.

## Running it locally

It must be **served**, not opened as a file, because a browser will not let a local file read
another local file:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Changing the incantation collection

```bash
# 1. edit incantations/incantations.json: add a line, or delete ones you rejected on the phone

# 2. check the JSON still parses
python3 -m json.tool incantations/incantations.json > /dev/null && echo valid

# 3. publish
git add -A && git commit -m "prune the collection" && git push
```

The live site updates about a minute later. Close and reopen the phone app to get past the cached copy.

Rules:

- **Never renumber `id`.** The device's keep/remove votes refer to ids, so renumbering silently
  reassigns your votes to the wrong lines.
- File order is rotation order. Reorder freely, it will not move the line already showing today.
- Adding at the end is safe; it gets reached at the end of the current cycle.
- To act on the votes stored on a device, open the counter at the bottom of the app, tap Copy, and
  use the exported `remove ids: ...` list to delete those entries here.
